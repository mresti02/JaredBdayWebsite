# Jared's Birthday Website

A fun birthday celebration page for Jared!

## Setup

```bash
npm install
```

## Scripts

| Command | Description |
|---------|-------------|
| `npm test` | Run the Jest test suite |
| `npm run lint` | Lint JS files with ESLint |

## Project Structure

```
JaredBdayWebsite/
├── src/
│   ├── index.html   # Main page
│   ├── styles.css   # Styles
│   └── app.js       # Birthday logic
├── tests/
│   └── app.test.js  # Unit tests
└── package.json
```
